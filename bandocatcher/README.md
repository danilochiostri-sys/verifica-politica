# BandoCatcher

MVP gratuito per aggregare finanziamenti, gare/appalti e concorsi, mantenendo sempre il link alla fonte ufficiale.

## Vertical slice v1
- PWA statica, nessun backend a pagamento
- catalogo fonti con livello di autorevolezza
- dataset demo normalizzato
- ricerca e filtri per categoria, territorio e stato
- scheda opportunità con requisiti e fonte ufficiale
- architettura pronta per ingestion Python/Supabase

## Principio
BandoCatcher organizza e rende ricercabile il dato; la fonte ufficiale resta il riferimento.

## Prossimo step
Sostituire il dataset demo con pipeline di ingestion versionata e Source Registry.
